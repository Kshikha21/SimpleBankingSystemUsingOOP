📌 Project Title:
Banking System in Java

📌 Description:
A simple Java-based banking system implementing OOP principles with account creation, deposits, withdrawals, and fund transfers.

📌 Features:
✅ Create Savings & Current Accounts
✅ Deposit & Withdraw Money (with overdraft for Current Accounts)
✅ Transfer Funds Between Accounts
✅ View Account Details
✅ Exception Handling for Invalid Operations

📌 Technologies Used:
Java (Core Java, OOP, Collections, Exception Handling)
IDE: IntelliJ IDEA / Eclipse / VS Code
Git & GitHub for Version Control
