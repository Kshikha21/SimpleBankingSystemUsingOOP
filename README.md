📌 Project Title:
Banking System in Java

📌 Description:
A simple Java-based banking system implementing OOP principles with account creation, deposits, withdrawals, and fund transfers.

📌 Features: <br>
✅ Create Savings & Current Accounts <br>
✅ Deposit & Withdraw Money (with overdraft for Current Accounts) <br>
✅ Transfer Funds Between Accounts <br>
✅ View Account Details  <br>
✅ Exception Handling for Invalid Operations  <br>

📌 Technologies Used:<br>
Java (Core Java, OOP, Collections, Exception Handling)<br>
IDE: IntelliJ IDEA / Eclipse / VS Code<br>
Git & GitHub for Version Control<br>
